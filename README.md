# Manufacturing and Assembly Guide: "Taurus-Air V6" Light Aircraft
**Author: Juho Artturi Hemminki**

## 1. Required Tools and Materials

### 1.1. Powertrain and Engine
* **Engine:** 1 pc Ford Taurus 3.0L V6 (Recommended: 1989–1995 SHO with Yamaha 24V heads and aluminum block. A standard Vulcan or Duratec block can also be used, but the top speed will be lower).
* **PSRU (Propeller Speed Reduction Unit):** A reduction gearbox with a 1.8:1 ratio (e.g., a geared or belt-driven PSRU) rated to withstand at least 250 Nm of torque.
* **Propeller:** 2-blade, ground-adjustable or in-flight adjustable (Constant Speed), maximum diameter of 1.60 m (to keep propeller tip speeds within the subsonic range).

### 1.2. Airframe and Material Package
* **Airframe Material:** A pre-fabricated single-seat kitplane fuselage or plans (e.g., chromoly steel tube or carbon fiber shell).
* **Cooling:** An aluminum high-performance radiator (e.g., a VW Golf or Honda Civic racing radiator) and an electric water pump (Davies Craig EWP).
* **Fuel System:** A high-pressure electric fuel pump (3.0 bar) and a surge tank to prevent air from entering the system during steep banks and turns.

## 2. Step-by-Step Assembly Instructions

### Phase 1: Engine Preparation and Weight Reduction (Aviation Conversion)
Automotive engines are inherently too heavy for aircraft use. Every kilogram added to the nose requires counterweight in the tail.
1. **Strip Accessories:** Remove the air conditioning compressor, power steering pump, stock alternator, and heavy cast-iron exhaust manifolds.
2. **Exhaust Manifolds:** TIG-weld lightweight, thin stainless steel headers (at least 1.5 mm wall thickness) that route exhaust gases straight backward underneath the fuselage. This provides a minor "jet thrust" effect to boost performance.
3. **Electronics:** Replace the vehicle's original heavy ECU with an open-source, tunable standalone engine management system (e.g., MaxxECU or Megasquirt) so that fuel and ignition maps can be adjusted during flight.

### Phase 2: Propeller Speed Reduction Unit (PSRU) Installation
The Ford V6 crankshaft is not designed to handle the gyroscopic and axial thrust loads generated by an aircraft propeller.
1. Mount the PSRU gearbox flange to the flywheel side of the engine block.
2. Ensure that the gearbox bearings absorb 100% of the propeller's pulling thrust.
3. Align the gearbox using a dial indicator to a tolerance under 0.05 mm to prevent premature belt or gear wear mid-air.

### Phase 3: Engine Mount Welding
The weight of the Taurus engine (~180 kg) significantly alters the aircraft's center of gravity (CG).
1. Use 4130 Chromoly steel tubing (19 mm diameter, 1.2 mm wall thickness).
2. Weld the engine mount so that the engine sits 5–10 cm further back from the firewall than a traditional aircraft engine. This maintains proper CG balance without adding dead weight (lead) to the tail.
3. Use high-quality polyurethane bushings on the engine mounts to dampen V6 engine vibrations.

### Phase 4: Cooling System and Intake Construction (Minimizing Cooling Drag)
The primary reason automotive engine conversions fail to achieve high speeds is poor aerodynamics around the radiator.
1. **NACA Duct:** Do not expose the radiator directly to the slipstream. Build a NACA inlet duct into the bottom or side of the fuselage.
2. **Diffuser:** Build an expanding duct (diffuser) in front of the radiator core to slow down incoming air (which improves cooling efficiency) and a contracting duct behind the radiator to accelerate the air back out. This minimizes cooling drag at speeds up to 340 km/h.

## 3. Engine Control Unit (ECU) Coding: Automatic Mixture and Fuel Tuning

As the aircraft climbs higher, the air becomes less dense. Without leaning the mixture, the Ford Taurus engine will run excessively rich and stall. This C++20 program module must be integrated into the aircraft's ECU to automatically adjust fuel delivery based on atmospheric pressure.

```cpp
#include <iostream>
#include <chrono>
#include <thread>

// Class to handle altitude compensation (Ford V6 in aviation use)
class AtmosphericFuelGovernor {
private:
    const float sea_level_pressure_kPa = 101.3f;
    const float stoichiometric_ratio = 14.7f; // Ideal stoichiometric air-fuel ratio (AFR) for gasoline

public:
    AtmosphericFuelGovernor() = default;

    // Calculates the optimal air-fuel ratio relative to atmospheric pressure
    float calculate_optimal_afr(float current_pressure_kPa) {
        if (current_pressure_kPa <= 0.0f) return stoichiometric_ratio;

        // As pressure drops (aircraft climbs), air density decreases.
        // The mixture must be leaned out by increasing the AFR value (more air relative to fuel).
        float pressure_ratio = current_pressure_kPa / sea_level_pressure_kPa;
        
        // During the climb to top speed, a slightly rich mixture is desired (Power Enrichment) for engine cooling.
        float target_afr = stoichiometric_ratio + (1.0f - pressure_ratio) * 1.5f;
        
        // Safety limit: Prevent the mixture from running too lean (max 16.0 AFR) to avoid melting the engine.
        if (target_afr > 16.0f) target_afr = 16.0f;
        
        return target_afr;
    }

    // Executes fuel injector pulse width correction
    void adjust_injection_timed(float target_afr) {
        std::cout << "-> ECU Correction: Adjusting injectors to target: " << target_afr << " AFR." << std::endl;
    }
};

int main() {
    AtmosphericFuelGovernor ecu_fuel;
    
    std::cout << "--- TAURUS-AIR AUTOMATIC MIXTURE CORRECTION ACTIVE ---" << std::endl;

    // Simulation: Aircraft climbs to an altitude of 1500 meters while accelerating to maximum speed
    float current_altitude_pressure = 85.0f; // Pressure has dropped from sea level
    
    float optimal_afr = ecu_fuel.calculate_optimal_afr(current_altitude_pressure);
    ecu_fuel.adjust_injection_timed(optimal_afr);

    return 0;
}
```
*Use this code with caution.*

## 4. Flight Testing and First Start

Before pushing the throttle to the stop to hit the 340 km/h mark, rigorous ground testing (Taxi tests) must be performed:
1. **Ground Run (Static Run):** Tie down the aircraft securely. Start the Ford V6 and run it at 4,500 RPM for 15 minutes. Monitor temperatures closely: if the temperature exceeds 100 °C on the ground, the NACA duct or radiator size must be increased before taking flight.
2. **High-Speed Taxi:** Raise the tail of the aircraft on the runway at a speed of 100 km/h, but do not take off. Test for vibrations in the PSRU gearbox and propeller.
3. **First Flight:** Take off, maintain a conservative 60% throttle position, fly within the airport traffic pattern, and verify that the engine management system (ECU) does not trigger any fault codes or activate a Check Engine light.
